05 / Engine 2

Dynamic Skill Gap Engine

Zero Static Tables

Skill gaps are computed dynamically on query. No stale cache tables or desynchronized data.

Deterministic Formula

Gap = max(Req - Curr, 0)

Strictly non-negative delta for every required skill in target role.

Role Readiness Score

R = (Σ Curr_w / Σ Req_w) × 100

Weighted readiness percentage based on skill importance factors.

Classification Thresholds: MASTERED: Gap = 0 PARTIAL: 0 < Gap < Req MISSING: Curr = 0
06 / Engine 3

Topological Roadmap Engine (Kahn's Algorithm)

Directed Acyclic Graph (DAG)

Every skill in the catalog has explicit prerequisite dependencies. Kahn's algorithm computes an in-degree topological sort.

Mathematical Guarantee: A dependent milestone $B$ (e.g. PyTorch) will never appear before its prerequisite $A$ (Python Fundamentals).

// Kahn's Topological Sort Execution 
in_degree = {u: 0 for u in skills}
for u, v in prerequisites:
    in_degree[v] += 1

queue = [u for u in skills if in_degree[u] == 0]
sorted_order = []

Bayesian Evidence Fusion

Upon submission, skill proficiency is updated through weighted Bayesian fusion rather than volatile overwrite:

P_new = round(0.30 × P_old + 0.70 × Score, 2)
